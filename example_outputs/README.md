# Example outputs

Files in this directory are demonstration snapshots generated from the repository's synthetic toy genomes or from earlier versions of the example workflow.

They are included for orientation only. They are not biological species results.

The current FastANI parser writes these preferred outputs:

```text
fastani_directional.tsv
fastani_pairwise_summary.csv
fastani_ani_matrix.csv
fastani_alignment_fraction_matrix.csv
```

Re-run the current scripts when you need outputs that match the latest code.

The legacy `pyani/` folder is retained only as historical example material. New method-comparison runs should use pyANI-plus and can be written to `example_outputs/pyani_plus/`.
